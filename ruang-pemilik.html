Memeriksa konfigurasi login...

Petunjuk menyiapkan autentikasi
  1. Buat proyek di Firebase Console, tambahkan aplikasi Web, lalu salin konfigurasi web ke firebase-config.js. Nilai konfigurasi web bersifat publik; jangan menaruh service-account key atau rahasia server di file ini.
  2. Aktifkan metode masuk Google di Authentication dan tambahkan domain jemaliseda-spec.github.io ke Authorized domains. Coba masuk sekali agar akun Google pemilik muncul di daftar Authentication; akses pertama akan ditolak sampai UID didaftarkan.
  3. Buat Firestore Database, salin isi firestore.rules ke tab Rules lalu terbitkan. Di Firebase Console buat koleksi dashboardAdmins dengan ID dokumen sama persis dengan UID akun Google pemilik dan field Boolean active: true.

Login ini mengunci tampilan dashboard untuk pengunjung biasa. Karena GitHub Pages menyajikan file statis yang tetap publik, jangan simpan informasi sensitif di halaman ini; data sungguhan harus dilindungi dengan aturan server.

Login terverifikasi untuk

Dashboard ini memakai login Google dan pemeriksaan akses Firestore. Situs portofolio tetap statis: pesanan pelanggan tidak tersimpan di sini. Simulator menggunakan grafik pasar publik untuk referensi, tetapi hanya mencatat transaksi virtual di browser ini; tidak terhubung ke broker, AI, atau transaksi uang nyata.
